Did your last code change make your docs wrong?

Give DocDrift a code diff and the Markdown files that describe it. A language model running on your own computer flags the sentences that may no longer be true and shows the changed code behind each one.

Check my own code

What it checks

DocDrift reads your diff and looks for documentation that describes something the change removed or renamed: command-line options, function names, default values, file paths.

Every finding quotes the exact sentence and the exact lines of the diff it is based on. If the diff does not clearly support a warning, the finding is marked uncertain.

Your text is only read, never run. It goes to Ollama on this computer and nowhere else. A clean result means no likely problem in the files you supplied, not that all your docs are up to date.

Set up the local model

  1. Install Ollama from ollama.com and start it.
  2. In a terminal, run ollama pull qwen3.5:4b.
  3. Come back here and check again.

Check your documentation

Paste the output of git diff, or upload a .diff or .patch file.

Documentation

Paste Markdown or upload one or more .md files. Line numbers in the results come from these files.
